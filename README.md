# combook-bridge（パパっと → ルクミー 橋渡しアプリ）

パパっと育児（jp.firstascent.papaikuji）のタイムラインを Android のアクセシビリティ機能で読み取り、
ルクミー Family（com.unifa_e.hiyoko.family）の連絡帳フォームへ転記する橋渡しアプリです。逆方向（ルクミー → パパっと）の書き込みにも対応します。

## できること
- 前日18:00以降のパパっと記録（食事・睡眠・排便・ミルク/授乳・体温・投薬の有無）を集計し、ルクミー連絡帳の下書きを作成
- ルクミーのフォームを自動入力し、送信確認の手前で停止（送信は必ず利用者が最終確認して行う）
- ルクミー側の記録（先生コメント・食事評価など）をパパっと側の記録形式に変換して書き込み
- 入力済みの項目は読み取ってスキップし、二重登録を防ぐ

## 仕組み
- アクセシビリティサービスで対象アプリの画面を読み取り・操作する、端末内完結型の実装です（サーバー通信なし）
- Gradle を使わない素の Java + `build.sh`（javac → d8 → aapt → apksigner）でビルドします

## 初回設定：アクセシビリティを有効にする（Android 13以降の「制限付き設定」）

このアプリはアクセシビリティサービスを使うため、インストールしただけでは有効化できません。Android 13以降、Playストア以外からインストールしたアプリは「制限付き設定」としてアクセシビリティ等が初期状態でブロックされます（Android標準の安全機能で、本アプリの不具合ではありません）。次の手順で許可してください。

1. アプリをインストールする
2. 端末の **設定 → アプリ → 「パパっとルクミー橋渡し」** を開き、アプリ情報画面の右上 **「⋮」→「制限付き設定を許可」** をタップし、PIN／生体認証で確認する
   - 「⋮」にこの項目が出ない場合は、先に手順3の画面で本アプリを選ぶところまで進めてください（「制限付き設定によって管理されています」とグレー表示されます）。その後アプリ情報に戻ると表示されます
3. **設定 → ユーザー補助 → ダウンロードしたアプリ → 「パパっとルクミー橋渡し」** を開いて **ON** にする（警告ダイアログが出たら内容を確認して許可する）

この許可はインストールごとに1回必要です。再インストールした場合は、同じ手順をやり直してください。

## 注意
- 対象アプリの画面仕様変更で動作しなくなることがあります
- アクセシビリティ API のポリシー上、Play ストアでの配布は想定していません（サイドロード専用）
- 公開版では署名用 keystore とランチャーアイコン画像は含まれていません。ビルド時に自分のものを配置してください
